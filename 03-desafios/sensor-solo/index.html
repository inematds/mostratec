Desafio 3 · Eletrônica · ESP32 · ★★★

O sensor que passou do limite

Este é o código de verdade da irrigação inteligente: um ESP32 lê um sensor capacitivo de umidade do solo e mostra a porcentagem num painel. O número do sensor cai quando a terra molha. Calcule o que o ESP32 guarda em cada variável.

Como o sensor é lido

int SECO = 3300, MOLHADO = 1400;   // calibração

void ler() {
  int bruto = analogRead(PINO_SOLO);           // 0 a 4095
  int pct = map(bruto, SECO, MOLHADO, 0, 100);
  umidade = constrain(pct, 0, 100);            // vai para o painel
}

O map() do Arduino/ESP32 faz a conta com números inteiros:

long map(long x, long in_min, long in_max, long out_min, long out_max) {
  return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min;
}
  1. Leitura A: bruto = 2350. Quanto vale pct?
  2. Leitura B: o vaso ficou no sol e bruto = 3500. Quanto vale pct?
  3. Ainda na leitura B, quanto vale umidade (o que o painel mostra)?

Sua resposta

Números inteiros. Se der negativo, use o sinal de menos.

Dicas

  1. Substitua na fórmula: x é o bruto, in_min é o SECO (3300), in_max é o MOLHADO (1400), out_min é 0 e out_max é 100. Repare que in_max é menor que in_min.
  2. Na divisão entre inteiros em C, a parte decimal é jogada fora, rumo ao zero: 7 / 2 dá 3 e −7 / 2 dá −3 (não −4).
  3. constrain(valor, 0, 100) devolve 0 se o valor for menor que 0, 100 se for maior que 100, e o próprio valor no resto.
